Simple, Elegant Syntax

main.cpp 

route("/api",api){
  Server.Response(connection,200,"OK",R"({"Messages":"Hello From Phoenix"})");
  return 200;
};

route("/api/env",api_list){
  std::string messages = R"({"Messages": "Hello From Env", "Env": ")" + 
  Server.env()["env"] + R"("})";

  auto result=Server.method.async([&](){
  Server.Response(connection,200,"OK",messages.c_str());
  });
  result.get();
  return 200;
};

Get Started in Seconds

Install Phoenix and start building high-performance web applications

1

Install Phoenix

curl -sSL https://get.phoenix-framework.dev | sh
2

Create a new project

phoenix new my-app
3

Start the server

cd my-app && phoenix serve
